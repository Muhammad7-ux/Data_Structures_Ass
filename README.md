# Data_Structures_Assignment

Python program that evaluates mathematical expressions from a text file
using a stack-based approach.

## Files
- `stack_evaluator.py` - source code
- `input.txt` - sample input
- `output.txt` - output generated by the program
- `test_errors.txt` / `test_errors_output.txt` - extra test for invalid input

## How to run
1. Install Python 3.10 or higher.
2. Open a terminal in the project folder.
3. Run: `python stack_evaluator.py`
   (Optional: `python stack_evaluator.py <input_file> <output_file>`)

## Input format
Each expression is on its own line. Expressions are separated by a line
containing only dashes, e.g. `-----`.

    3 + 5 * 2
    -----
    (8 / 4) + 7 * 2

## Output format
Same layout as the input, with each expression replaced by its result.

    13
    -----
    16

## How it works
Two stacks are used: one for numbers and one for operators. Operators with
higher precedence are applied first (`*` and `/` before `+` and `-`), and
parentheses are resolved before the rest of the expression.

## Assumptions and limitations
- Supported operators: `+`, `-`, `*`, `/` and parentheses.
- Blank lines in the input are ignored.
- Invalid expressions (e.g. `3 + * 2`) and division by zero produce an
  error message in the output instead of crashing the program.
- Negative numbers written directly (e.g. `-5 + 3`) and exponents are not supported.
- Note: the sample output in the assignment sheet shows 17 for
  `(8 / 4) + 7 * 2`, but the correct answer is 2 + 14 = 16, which is what
  this program outputs.
